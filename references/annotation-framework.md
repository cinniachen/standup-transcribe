# 五维喜剧分析框架

本文件用于分析脱口秀段子的喜剧技法。不要把它原样塞进最终文档；最终文档要翻译成学习者能用的语言。

## 维度一：核心四要素

用于判断一个bit的底层质量，不一定作为标签出现。

- 好笑：是否真的产生笑点或预期落差。
- 真实：素材是否来自真实情绪、真实处境或可信观察。
- 原创：角度是否有个人独特性，而不是常见吐槽。
- 对话感：是否像一个人在自然表达，而不是论文或口号。

## 维度二：素材质量

分析素材为什么适合或不适合做喜剧：

- 真实性：观众是否相信这事/这情绪是真的。
- 个人化：是否和表演者身份、经历、气质有关。
- 宜人度：冒犯风险是否被自嘲、荒诞、距离感化解。
- 熟悉度：观众是否能快速进入场景。
- 普适性：个人经历是否能连到大众经验。
- 荒谬点：事实中最不合理、最拧巴、最可笑的地方是什么。

## 维度三：结构逻辑

关注bit怎么搭起来。

常用标签：

- 引子：把观众带入话题。
- 论点：这段想表达的核心判断。
- 分论点：支撑主论点的小判断。
- 荒诞点：指出不合理或冲突。
- 例证：具体故事、场景或人物。
- 铺垫：让后面的笑点成立。
- 收尾：结束bit或回收前文。

分析时要问：

- 这个bit是议论文式，还是故事式？
- 论点是否清楚？
- 铺垫是否足够短？
- 笑点是否依赖前面信息？
- 有没有可删掉的冗余信息？

## 维度四：观点提炼

单口喜剧里的观点通常不是"正确观点"，而是"带情绪的个人判断"。

公式：

```text
观点 = 事实 + 负面情绪
```

常见负面情绪：

- 困难
- 奇怪
- 害怕
- 愚蠢
- 委屈
- 尴尬
- 荒唐

分析时要写清：

- 事实是什么？
- 负面情绪是什么？
- 为什么这个情绪观众能理解？
- 这个观点有没有个人独特性？

## 维度五：加梗技术

常用标签：

- 笑点：包袱释放点。
- 呈现：Act-out，直接演出来。
- 比喻：用画面感解释感受。
- 类比：把两个领域放在一起制造理解或错位。
- 夸张：把局部事实放大。
- 假设：假设动机、后果或极端场景。
- 混合：把不相关事物连起来。
- call-back：回收前文信息。
- 反转：打破观众预期。
- 二次反转：反转后再翻一次。
- 自嘲：把自己放进笑料里。
- 金句：简短、有记忆点、能独立传播。
- 递进：一层比一层强。
- 排比：用重复句式形成节奏。
- 反讽：表面赞成，实际否定。
- meta笑点：调侃表演、节目或段子本身。
- 解构：拆掉一个习以为常的概念。
- 极简收束：长铺垫后用短句落地。
- 误导：把观众带向错误预期。
- 悬念：暂时不揭示关键信息。
- 对比：制造落差。

## 标注深度标准

差的注释：

```text
这里用了反转，很好笑。
```

好的注释：

```text
前半段把观众带向"她很坚强"的预期，后半段突然落到一个很日常、很狼狈的小反应，英雄形象和普通人反应形成落差，所以笑点成立。学习点是：先抬高人物，再用具体细节把她拉回普通人。
```

每条重点注释至少回答两个问题：

1. 为什么好笑？
2. 学习者可以怎么迁移？
