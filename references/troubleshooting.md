# 成功标志和排查步骤

## 成功标志

快速转录成功：

- 生成带时间戳转录稿。
- 生成纯文本稿。
- 文档能正常打开。

完整学习笔记成功：

- 有完整转录稿。
- 有按bit/话题块整理的精华分析。
- 有技巧标签、为什么好笑、可学习点、可迁移写法。
- 有金句收藏、结构图、风格总结、练习题。

云文档发布成功：

- 有本地备份文件。
- 有在线文档链接。
- 链接打开后内容完整。

## 常见问题

### 找不到ffmpeg

现象：

```text
未找到ffmpeg
```

处理：

1. 安装ffmpeg：`brew install ffmpeg`。
2. 确认终端能找到ffmpeg：`which ffmpeg`。
3. 如果装在特殊位置，把路径加入系统PATH。

### 没安装Whisper

现象：

```text
ModuleNotFoundError: No module named 'whisper'
```

处理：

```bash
pip install openai-whisper
```

### 视频太长

现象：

- 转录很慢。
- 文档太长，不适合学习。

处理：

1. 建议拆成10-30分钟片段。
2. 或只生成完整转录，标注只选精华bit。

### 人名错误

现象：

- 同一个人名出现多个版本。
- 行业人物被转成普通词。
- 国外演员名音译混乱。

处理：

1. 让用户提供表演者、嘉宾、节目名、人名表。
2. 列出可疑词让用户确认。
3. 把修正传入 `corrections`。
4. 长期常用修正写入 `scripts/names.json`。

### 文档太长没人看

处理：

1. 完整转录保留。
2. 标注只选高价值bit。
3. 在开头增加"一句话总览"和"最值得学的5件事"。
4. 把练习题控制在5-8个。

### 云文档上传失败

处理：

1. 确认本地Word已生成。
2. 不重新转录。
3. 检查平台凭证。
4. 只重试上传步骤。
