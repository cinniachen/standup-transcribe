# 学习笔记输出模板

最终文档要像学习资料，不像机器日志。

## 推荐结构

```markdown
# 标题

## 0. 基本信息

- 素材：节目/视频/音频名称
- 表演者：
- 时长：
- 处理方式：完整转录 + 精华bit标注
- 输出日期：

## 1. 一句话总览

用2-4句话说明这段内容最值得学什么。

## 2. 完整转录稿

保留完整文本。时间戳可以按段落或bit块出现。

## 3. 整场结构图

用列表或表格写：

| 顺序 | 时间戳 | bit/话题 | 功能 | 主要技巧 |
|---|---|---|---|---|

## 4. 精华bit拆解

每个bit使用下面结构：

### Bit 1：名称

- 时间戳：
- 原文/摘要：
- 五维观察：
- 技巧标签：
- 为什么好笑：
- 我能怎么学：
- 可迁移写法：
- 可选练习：

## 5. 金句收藏

| 金句 | 为什么值得收藏 | 可迁移方向 |
|---|---|---|

## 6. 表演者风格总结

写5-8条，避免空泛夸奖。

可以从这些角度总结：

- 常用题材
- 常用情绪
- 常用结构
- 常用技巧
- 人设/气质
- 和观众的关系
- 最值得学习的地方

## 7. 创作练习题

至少给5个练习：

- 2个仿写练习
- 1个个人经历迁移练习
- 1个观点提炼练习
- 1个改写练习

## 8. 附录

- 可疑人名修正
- 处理说明
- 本地文件路径
- 可选在线文档链接
```

## Bit拆解写法

每个重点bit应该服务学习者。

推荐写法：

```markdown
### Bit：健身房像职场

- 时间戳：05:12-07:40
- 原文/摘要：表演者把健身房里抢器械、互相观察、假装专业的行为，类比成小型职场。
- 五维观察：熟悉场景 + 负面情绪"尴尬/竞争" + 明确荒谬点。
- 技巧标签：类比、观察、递进、呈现
- 为什么好笑：健身房本来是身体训练空间，但表演者把它解释成职场权力空间，两个系统混合后产生错位。
- 我能怎么学：找一个大家熟悉的日常场景，再套入另一个更严肃的系统。
- 可迁移写法：A不是A，A其实是一个小型B。
- 练习：把"排队买咖啡"改写成"小型高考"。
```

## 精华比例

30分钟以内素材：

- 完整转录保留100%。
- 技巧标注精选30%-50%的高价值内容。
- 过渡句、重复口头禅、纯铺场可不标。

超过30分钟素材：

- 先建议拆分。
- 如果用户坚持，标注只选最有学习价值的bit。
